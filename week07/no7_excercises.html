第5回授業実習課題：CSSの記述方法

この実習課題のスタイル指定は、CSSを記述したらプレビューを更新、記述したらプレビューを更新、という手順で結果を確認しながら進めてください。意図通りにならない場合には、コードを見直すこと。なお、Web サーバ上に置いたコンテンツは、Webブラウザのキャッシュが残っているために、スタイル情報がすぐには更新されないことがありますので、注意してください。また、PC上で更新したデータはFTPを使ってアップロードし(直さ)ないとWebサーバ上に反映されない点も確認しましょう。

この実習はVS Codeの「Live Preview」でプレビューをおこないながらをします。行が長い場合はAlt + Z (macOS: option + Z)で行の折り返しをしてください。

実習を始める前に、HTML文書の最後にあるfooter要素の中の *your name here* のところにあなたの名前をアルファベットで、また、address要素にある your_email_address_here@reitaku.jp をあなたの電子メールアドレスに書き換えておいてください。

実習課題 No. 0

基本練習1: style属性の記述 (資料p.4, §2.4)

以下のp要素にstyle属性(style="...")を追加し、1字字下げのスタイルを適用してみよう(style="text-indent: 1em")。p要素の開始タグに、直接style属性を書き込む。VS Codeのコード補完機能を活用しましょう。次に、p要素の中の2つめのspan要素にstyle属性を追加しよう(style="font-family: 'Osaka-mono', 'MS Gothic', 'monospace'; background-color: khaki")。1つめのspan要素には、style属性が記述ずみなので、参考にするとよい。

この段落を1字字下げします。1字字下げのCSSは text-indent: 1em と記述します。基本となるフォントのスタイルは font-family というCSSのプロパティで設定します。例えば、コンピュータのコードなどに使う等幅フォントで表現したい場合、CSSで font-family: monospace という記述をおこないます。

基本練習2: style要素に記述されたスタイルの利用 (資料p.4, §2.3)

このHTML文書のhead要素の中にstyle要素があり、その中でborder-radiusとgradientという2つのclassに適用するスタイルが指定されている。以下のp要素にclass属性をそれぞれ指定し、style要素の中に記述されたスタイルを適用してみよう。

角丸スタイル：class="border-radius"

border-radius をここに指定しなさい。画像を使わずに角丸を表現することができます。

グラデーションの表現：class="gradient"

gradient をここに指定し、グラデーションを表現しなさい。

基本練習3: スタイルシートファイルの追加 (資料p.3, §2.2)

VS Code でスタイルシートを新規作成します。ファイル名「no7.css」(全て半角小文字)をつけ、新規スタイルシートを「2026web」フォルダの中の「css」サブフォルダに保存する。(なお、この課題ファイルは「2026web」フォルダの中に直接保存すること。)

上記の作業の結果、HTMl文書のhead要素にlink要素が追加され、作成したスタイルシートファイルがリンクされる。スタイルシートファイルは「ソースコード(HTML文書)」とタブを切り替えながらVS Codeの中で編集することができる。

基本練習4: スタイルシートファイルの利用 (資料p.4, §2.4)

スタイルシートno7.cssにスタイルを記述してみよう。基本的なスタイルの記述方法は「セレクタ { プロパティ : プロパティの値 }」である。HTMLの基本のフォントサイズとして10px (ちょっと小さめ)を指定しよう。body要素をセレクタとしてフォント指定をおこなう。また、background-image プロパティを使い、背景画像 blue.jpg を表示させよう。さらに、左右の余白を空けるよう、main要素をセレクタとして、以下のようにCSSを記述する。

@charset "utf-8"; /* 文字エンコードを記述 */
body { 
    font-size: 12px;
    line-height: 1.7;
    background-image: url("../img/blue.jpg");
    font-family: "Kosugi", sans-serif; /* Webフォント (Google Fonts) の Kosugi フォントを使用 */
}
main {
    max-width: 1120px;
    margin: auto;
    padding: 0 1.5rem;
}

画像ファイルは「2026web」の中の「 img 」フォルダの中に入れてある。スタイルシートに記述している参照パス(url("../img/blue.jpg"))は、「cssフォルダから2026webフォルダに出て(../)、imgフォルダに入り(img/)、imgフォルダの中のblue.jpgを表示する」ことを表わしている。

スタイルシートのⅠ行目には、@charset "utf-8"; というスタイルシートの文字エンコードの記述があるので、スタイルはその後に書いていくようにしよう。

スタイルシートファイルの内容は上から順番に適用されていくので、標準的なスタイルを先に書いておくのが基本である。基本練習4のスタイルは重要なスタイル情報なので、今回のように最初に書いておこう。以下の実習課題のスタイルはこのスタイルの下に続けて記述していくこと。

実習課題 No. 1 (資料p.6, §3.2)

サイズ指定に使う単位の指定

練習

id="ex1" が指定された article 要素とその子要素のスタイルについて、以下を設定しなさい。

/* 実習課題 No. 1 */
#ex1 { font-size: 20px; }
#ex1 section { font-size: 16px; }
#ex1 h2 { font-size: 1.5em; }
#ex1 p { font-size: 0.8em; }
  1. px (ピクセル) を使って画面ピクセルに対する相対サイズを指定する。
    • section要素：20px
    • article要素：16px
  2. em (1文字分の倍数) を使って親要素を基準とする相対サイズを指定する。
    • section要素の中のh2要素：1.5em
    • section要素の中のp要素：0.8em

実習課題 No. 2

フォントの種類や太さ、装飾に使うプロパティ

練習

id="ex2" が指定されたarticle要素およびその子要素のスタイルについて、以下を設定しなさい。

/* 実習課題 No. 2 */
#ex2 { font-weight: 400; } /* 400 が基準、100から9000まで±100単位で指定 */ 
#ex2 section { font-weight: 400; line-height: 1.75; } /* font-weight プロパティは 100～900 までの範囲を100ずつ区切って指定する。標準は400 */ 
#ex2 h2 { font-weight: 500; letter-spacing: 10px; text-align: center; }
#ex2 p { font-weight: 300; text-decoration: underline; text-indent: 1em; }

実習課題 No. 4

色の指定方法（αチャンネル）

練習

id="ex4" が指定された要素のスタイルについて、以下を設定しなさい。

/* 実習課題 No. 4 */
#ex4 { color: #FF00FF; /* red */ }
#ex4 h2 { background-color: rgba(0, 86, 172, 0.5); } /* 最後の0.5は不透明度の値。αチャンネルを使って半透明にしない場合は rgb() を使う。 */
#ex4 p { color: hsla(128, 40%, 70%, 0.1); } /* hsla の最後の0.1は不透明度の値。αチャンネルを使って半透明にしない場合は hsl() を使う。 */

実習課題 No. 6 (資料p.6, §3.1に概略あり)

ボックスモデル：サイズ、間隔、配置の3要素の調整 (2)

練習

id="ex6" が指定された要素のスタイルについて、余白 margin プロパティと詰め物 padding プロパティを設定しなさい。

/* 実習課題 No. 6 */
#ex6 { 
  margin: 10px 40px 10px 30px; 
  padding: 10px; 
  border: solid 1px #8b7348;

margin, padding とも、上から時計回りに余白を記述する。2箇所の場合は上下・左右の順で、1箇所の場合は上・右・下・左全ての余白を同一の長さで設定する。

実習課題 No. 7 (資料p.6, §3.1に概略あり)

ボックスモデル：サイズ、間隔、配置の3要素の調整 (3)

練習

id="ex7" が指定された要素のスタイルについて、幅と長さを指定しなさい。

/* 実習課題 No. 7 */
#ex7 p { 
  margin: 5px auto; 
  padding: 10px; 
  width: 40%;
  border: solid 10px red; 
  background-color: #FFCCFF;
}
  1. width (, height) プロパティを使ってp要素の画面上の相対サイズを指定する。
    • width プロパティ: 40%
  2. p要素を中央揃えしなさい。margin プロパティで左右を auto に設定する。
    • p 要素の margin-left プロパティ：auto
    • p 要素の margin-right プロパティ：auto
